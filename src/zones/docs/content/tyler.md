# Tyler

unenter.live is built and operated by one developer: **Tyler**.

## What that actually means

Most solo developers rent their infrastructure and glue together other people's platforms. Tyler built the platform itself:

- **UNAXIS** — a full terminal control plane for the platform, with its own custom-built rendering engine (a from-scratch React reconciler for the terminal), its own CLI, and remote agents coordinating multiple machines.
- **15+ zones** running as independent apps on one domain, each built, shipped, and monitored through UNAXIS with a single command.
- **A two-machine, self-hosted fleet** — one machine for development and orchestration, one as an agent host — running the entire public platform from hardware he owns.
- **The full stack, end to end** — frontend, backend, database, storage, proxy, CI-style build pipeline, backup and restore system. All of it in-house.

## The philosophy

> A project is code plus data. Everything else should be rebuildable by the system, on command, without drama.

That idea runs through everything here: apps ship as immutable images, data lives in restorable snapshots, and one operator system keeps every moving part visible.
